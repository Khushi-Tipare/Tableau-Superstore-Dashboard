
# Superstore Sales & Profit Analytics Dashboard

## 📌 Project Overview
Interactive Tableau dashboard built using the Sample Superstore dataset to analyze sales, profit, return rate, customer segments, and regional performance. The dashboard provides actionable business insights through dynamic visualizations and KPI metrics.

---## 📂 Dataset used 
<a href="https://github.com/Khushi-Tipare/Tableau-Superstore-Dashboard/blob/main/sample_-_superstore.xlsx">Dataset</a>
 
## Dashboard Features
- Sales & Profit Analysis
- Regional Performance Tracking
- Customer Segment Insights
- Category & Sub-Category Analysis
- Return Rate Monitoring
- Interactive Filters and Visualizations

---

## Tools & Technologies
- Tableau
- Data Visualization
- Business Intelligence
- Data Analytics

---

## Key Insights
- Technology category generated the highest sales.
- West region showed strong overall profitability.
- Certain sub-categories had high sales but low profit margins.
- Consumer segment contributed the largest share of sales.
